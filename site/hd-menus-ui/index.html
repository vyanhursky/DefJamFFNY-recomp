Texture coverage and resolution

The pack contains 1,787 PNG files, 1,565 native texture mappings and 80 widescreen registrations. These measure different things: aspect-specific scenery exports and registrations are included in the PNG total.

All 1,565 mapped native replacements measure 4× the source width and height, or 16× as many pixels. Examples measured from the current package:

Artwork Original HD

Widescreen scenery also extends the composition; it is not a uniform enlargement of a 4:3 screen. Technical masks, grids and other deliberately unchanged game inputs remain source-held where required.

The unchanged game-pack payload is 615,807,576 bytes (615.81 MB / 587.28 MiB) unpacked in 1,792 files. The current source archive is 613.08 MB; the Thunderstore wrapper has its own download size.

How it was made

AI-assisted restoration with OpenAI ImageGen, source-aligned assembly and manual review. Restoration briefs asked for sharper artwork, lettering and material detail while preserving the original game's illustrated style, colors and typography. Lettering, glyph placement, transparency and seams were checked and revised before selection; lossless PNG optimization reduces download size without changing decoded pixels.

Get started

Install

Requires Def Jam Recompiled 0.12.1 or later for the underlying texture pack.

Launcher: open Mods, refresh the catalogue, install HD Menus and UI, enable it and restart the game. The catalogue currently offers the compatible R2-hosted release. Automatic installation of this Thunderstore wrapper awaits a launcher release that supports it.

Manual Thunderstore download: extract only the menu-ui-hd-wide-v1-7-1 folder into the mods folder inside your Def Jam Recompiled data directory. Enable the local pack in the launcher's Mods page and restart the game. Keep the folder's manifest.ini, components, textures and other contents together. Local installations do not receive managed catalogue updates; disable another copy of this same menu pack to avoid duplicate loading.

This download targets Def Jam Recompiled. Emulator packages require a separate conversion and validation.

Version 1.7.2 and testing

1.7.2 repackages the licensed 1.7.1 game pack for Thunderstore. The inner folder retains its source version; all game-pack files, artwork and licence notices are unchanged. No new restoration or game-runtime change is included.

Representative macOS playtesting covers HUD/pause at 4:3, 16:9 and 21:9, plus quit confirmation, combat and results. Dedicated tutorial states, every controller/localization variant and exhaustive cross-platform coverage have not all been tested in-game.
