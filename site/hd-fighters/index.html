A character texture restoration pack for Def Jam: Fight for NY Recompiled

This texture pack upscales and restores the faces, clothing, and bodies of all of the game's fighters. The upscaled textures apply to models in battles and story mode. It uses the original models, rigs and animations and leaves gameplay unchanged.

The new textures improve the clarity of clothing details, faces, and tattoos. We located reference photos from the early 2000's to pinpoint and restore specific fighters' tattoos, clothing, and jewelry.

The restoration work was completed with the help of OpenAI Imggen, as well as Google NanoBanana. Each texture has been reviewed and revised multiple times to fix small details and stay true to the original look and style of the fighters.

Pack coverage

What's included

218 texture entries covering the fixed roster's main outfits, additional outfits, identified in-engine Story states and secondary/injury maps:

The pack covers 69 named characters, including Story/NPC characters, through 80 unique main/outfit/Story atlases (69 base + 11 additional). It also includes 132 injury maps, one uninjured secondary head texture and 5 shared inputs.

Get started

Install this Mod

For Def Jam Recompiled 0.12.1 or later, with your own supported game installation.

Install from Def Jam FFNY Recompiled Launcher

  1. In game launcher, open Mods > Textures > Browse
  2. Press the Refresh Catalogue button
  3. Select HD Fighters, then Install/Update.
  4. HD Fighters will appear under Installed Mods.
  5. Enable the mod by checking the On checkbox in the mod table
  6. Ensure HD Fighters has priority in the load over local "Recomp HD" or "Faithful HD" textures.
  7. Restart or Launch the game.

Manual Install from Thunderstore

Use these steps if you are working with a different recomp (e.g. FFNY-online) or emulator

  1. Use Download on this page and open the ZIP.
  2. Extract the included hd-fighters-v* folder into mods inside your Def Jam Recompiled data folder. Keep that folder intact, including its manifest.ini and textures directory.
  3. If the game launcher or emulator has a mod manager, ensure the modpack is enabled and load order is properly configured.
