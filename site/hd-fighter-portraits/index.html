Pack coverage

Portraits throughout the menus.

The pack contains 2,184 native replacement PNGs: 1,334 Select/Story/team/roster/result textures and 850 loading textures covering 294 two-, three- and four-player layouts. Atlas fragments and variants are included in the PNG count; it is not a count of separate fighter portraits.

All replacements measure 4× the original width and height, or sixteen times as many pixels. Measured examples:

Head / roster texture64 × 64256 × 256
Portrait atlas128 × 256512 × 1024

Several native atlas pieces can form one full-body composition. The assembled canvas dimensions shown beneath those sliders describe the complete portrait rather than one PNG.

The licensed 1.0.1 download is 751.2 MB; the unpacked payload is 752.4 MB. The prepared Thunderstore 1.0.2 edition is 752.4 MB and contains the same approved portrait artwork and licence notices.

Menu backgrounds, typography, fighter name banners and UI icons belong to HD Menus and UI. In-fight 3D character textures belong to HD Fighters. Each pack can be used independently or together; Faithful HD is optional.

How it was made

AI-assisted restoration using OpenAI ImageGen, original-geometry assembly, manual corrections and owner review. Faces, clothing and small details were compared against the source art; approved revisions were mapped back into the native texture layouts. Lossless PNG optimization preserves the released pixels.

Get started

Install the portrait pack.

Requires Def Jam Recompiled 0.12.1 or later with texture-pack support. No game rebuild or reinstall is needed.

Launcher: open Mods, refresh the catalogue, choose HD Fighter Portraits, download and install it, then enable the pack and restart the game. The signed catalogue controls which compatible version is offered.

Manual download: extract the hd-fighter-portraits-v1-0-1 folder containing manifest.ini into your game data folder’s mods directory. Keep its contents together, enable it in the launcher and restart. Disable another copy of this same portrait pack to avoid duplicate loading.

If using the older combined Menus 1.5 pack, update Menus to 1.6 or later alongside installing Portraits. Release history, downloads and installation details ↗

Versions and validation

1.0.1 adds the contribution licence and attribution notices to the previously approved artwork. The 1.0.2 Thunderstore wrapper preserves all 2,189 inner files, including the 2,184 PNGs, native mappings and both licence files. Storefront publication and launcher catalogue updates are separate from artwork approval.

Representative macOS Select/loading checks cover 4:3, 16:9 and 21:9 configurations, with Portraits alone and alongside Menu/UI. They do not certify every fighter, layout or platform.
