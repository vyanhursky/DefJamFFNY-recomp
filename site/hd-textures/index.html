Story Mode Customization

What's included

This texture pack contains 4961 upscaled customization textures for Story Mode characters - clothes, tattoos, jewelry, and hair. All 5000 textures were meticulously reviewed to stay faithful to the original game while restoring lost detail to the 2000's era fashion.

This work was done with AI-assisted restoration - OpenAI Imagegen, source-aligned assembly and repeated manual review. The original geometry, outfit construction and gameplay remain unchanged.

Get started

Install one tier.

Def Jam Recompiled launcher

  1. Open Mods → Textures → Browse and refresh the catalogue.
  2. Choose HD Textures - High, or choose Medium or Ultra instead.
  3. Install and enable that tier. Disable another copy or quality level of this pack.
  4. Give it priority over a local Faithful/Recomp HD pack, then restart the game.

Manual Thunderstore installation

  1. Download one quality level and open its ZIP.
  2. Extract the included pack folder into mods inside your Def Jam Recompiled data folder. Keep manifest.ini and its texture folders together.
  3. Refresh local mods, enable that tier and restart. Manual local copies do not receive managed catalogue updates.

Requires Def Jam Recompiled v1.2.4 or newer. Other ports and emulators need separate format and identifier validation.
