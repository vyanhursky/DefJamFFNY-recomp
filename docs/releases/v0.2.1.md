# v0.2.1 — Terrordome crash fix

A bug-fix release for v0.2.0.

## Fixed

- **Matches at the Terrordome no longer freeze and close.** One of the fighter
  state functions returned without running its exit code, which left the game's
  stack misaligned and sent the per-frame loop over the fighters into unrelated
  memory. The crash was present in v0.1.0 and v0.2.0 and showed most reliably in a
  four-fighter Free For All.

  The cause was in the translation, not the game: a jump to the function's shared
  exit had been replaced by an empty placeholder. That exit and six others of the
  same shape elsewhere in the program are now translated as code.

## Build this version

```powershell
git clone --recursive --branch v0.2.1 https://github.com/vyanhursky/DefJamFFNY-recomp.git
cd DefJamFFNY-recomp
```

If you already built v0.2.0, update the checkout and rerun the whole pipeline: the
list of function seeds changed, so the analysis and the generated code must be
regenerated before building.

```powershell
git fetch --tags
git checkout v0.2.1
git submodule update --init --recursive
.\scripts\analyze.ps1
.\scripts\recomp.ps1
.\scripts\build.ps1 -Preset win-x64-release
```

Follow [Build and play](../build-and-play.md) with your own supported USA Xbox
dump. This is a **source release**: no game data, generated code or executable.
Saves and `settings.ini` from v0.2.0 carry over unchanged.

## Validation

On the Release build (Windows 11, 2560x1440 at 120 Hz):

- A scripted four-fighter Free For All at the Terrordome ran four minutes three
  times without a crash; before the fix the same script crashed within minutes.
- A scripted One on One at the Terrordome ran four minutes three times without a
  crash.
- The full regression run was started on the fixed build and stopped part-way at the
  owner's decision once the Terrordome runs were clean; it did not complete. The fix
  regenerated all translated code, with seven placeholders replaced and none added.

## Known limits

- The translation still contains about a hundred placeholders for jump targets it
  could not resolve. Roughly seventy look like real code that is not a simple
  exit; they need a change to how the translator finds the ends of functions and
  are tracked as follow-up work. `python scripts/stub-targets.py` lists them.
  None is known to be reached in play.
- Why the Terrordome triggered the fault more than other venues is not known.
- Everything listed for v0.2.0 still applies.
