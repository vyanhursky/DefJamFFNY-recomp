# v1.2.0 beta 2 — Fighter Mod Support, second experimental build

This is an opt-in experimental prerelease for testing custom fighters. Stable
v1.1.1 remains Latest. The app does not offer prereleases as automatic updates;
download this beta manually. Its interface reports version 1.2.0.

You need your own supported USA Xbox dump. The game-free app verifies it and
compiles locally. No game executable or game data is distributed. Fighter packs
and their converted assets are not included.

## What is new since beta 1

- **Install a pack by dropping it on the launcher.** Mods > Fighters has a drop
  zone and a Browse button for the Fighter ZIP, so the path no longer has to be
  typed. A progress bar with percent, size and elapsed time sits under the
  buttons, with Cancel beside them. The step that compiles a large roster has no
  measurable size, so there the bar keeps moving with the clock; it took two to
  three minutes for a 46-fighter pack in development.
- **One format for created fighters.** Custom-fighter recipes are a single
  `caf-fighter-1` format with optional sections, stored in one `fighter-caf.bin`
  container. Nothing before this beta read CAF recipes, but recipes exported by
  earlier Workshop builds (`caf-fighter-2` to `-6`) are refused: export again
  with the matching Fighter Workshop.
- **HD created-fighter textures.** HD CAF atlases work through the
  existing texture cache, as an optional section of the same format. Native
  256 px allocations are unchanged.
- **Outfit-specific selector titlecards** show the fighter's chosen outfit.
- **Much faster relaunch.** A launch with unchanged packs reuses a verified
  composition instead of recompiling the roster: 159 s cold to 12 s warm on a
  46-fighter test roster. Anything changed in a pack, the game files or the
  settings that matter builds fresh.
- **Fixes from a code review of the fighter work:** a fighter with several
  outfits no longer stops the match when none was confirmed (it plays the
  default outfit); every fighter module now stops through one dialog that says
  what happened instead of closing the window; a face sculpt is looked up
  before the head layout is checked, so a fighter without a sculpt is not
  stopped by one; a Story moveset that cannot be honored falls back to the
  career core instead of stopping the game; and two UI command prefix checks
  were off by one.

## Testing and limits

The Windows stock regression passed **17 of 17 applicable checks** (four checks
for the macOS/Linux launcher skipped as inapplicable) in 46 minutes, with
1,917 unit tests passing. The launcher change was added after that run and was
checked with the unit suite (1,918 passed), the main-menu boot check and real
launcher runs: a drop, a Browse, a full install with progress, Cancel, and a
corrupt ZIP.

Windows play with two fighter packs under development reached the results
screen, including outfits, face sculpts and 1024 px HD textures. These runs do
not establish that every fighter or animation is correct.

Fighter Mod Support remains experimental. Not verified in game: the default
outfit fallback for a random or CPU pick, Rematch, every 2-, 3- and 4-player
layout, and edited saves carried over from v1.1.1 or v1.2.0-beta.1. Windows
is the main qualified platform. A full regression on a Steam Deck (SteamOS,
built from this source) passed 19 of 21 checks: replay matched 79 of 80 records,
the same Deck-only difference as before, and three unit tests failed on the
Zig toolchain, not on the game. A fighter pack with three outfits installed,
enabled and played to the match summary and save on the Deck, but its launcher
Fighters page, 3- and 4-player routes and the CI AppImage install were not
tried. macOS is built and compiled by CI only and has not been played. Full
M5/M6 acceptance remains open. Known issues carried from stable include
[memory investigation #166](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/166)
and [Steam Deck replay differences #98](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/98);
this beta does not close them.

Use a backup or separate test installation. Back up the complete data folder,
including managed fighter progression and song preferences. Do not restore
individual old save files or delete adoption markers after managed Play.

Please report the exact beta and pack versions, fighters, venue, match rules and
whether the fault follows Rematch or returning to selection. Press F9 after a
problem to create a local bug bundle; review it before sharing.
