# v1.2.4 — Story customization HD support and build cleanup

Adds runtime support for compatible Story customization HD source packs and
reclaims space from obsolete installation builds after successful activation.

You need your own supported USA Xbox dump. The game-free app verifies it and
compiles locally; no game executable, game data or texture pack is included.
Source builds use recursive tag `v1.2.4`; see the [Windows](../build-and-play.md)
and [macOS/Linux](../build-macos-linux.md) guides.

## Changes

- **Story customization HD source packs:** enabled packs declaring `story-caf-v1`
  can replace clothing, skin, hair, tattoo and jewelry source layers. The runtime
  follows native layer composition and palette changes, preserves native material
  alpha and allocation sizes, and falls back to native rendering for missing or
  unsupported inputs. Restored tattoo/source alpha survives blending. Existing
  authored custom-fighter HD recipes retain priority under shared memory pressure.
  Packs require recomp **1.2.4 or newer** and the capability declaration; this
  release does not publish any pack or catalogue entry. See [the contract](../research/story-caf-hd-compositor.md)
  and [PR #318](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/318).
- **Obsolete-build cleanup:** after successful, durable activation, setup retains
  the active build and its actual immediate predecessor for rollback, then removes
  older generated builds and abandoned attempts. Data, the supplied dump, redirected
  paths, unknown folders and the running setup host are protected. Locked obsolete
  files defer cleanup without failing the installed game. Failed activation never
  prunes. See [PR #299](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/299).
  This does not compact existing save images or close the broader [disk-space issue #180](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/180).

and source/toolkit provenance. Keep your existing data folder when updating.
The tag workflow prepares a draft; stable publication is separate from tagging.
