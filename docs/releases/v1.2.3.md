# v1.2.3 — Save import and subtitle sizes

Import Xbox and PS2 Story saves from launcher **Help → Saves → Import saves…**,
choose larger speech subtitles, and see mod update notices on Home.

You need your own supported USA Xbox dump. The game-free app verifies it and
compiles locally; no game executable or game data is included. Source builds
use recursive tag `v1.2.3`; see the [Windows](../build-and-play.md) and
[macOS/Linux](../build-macos-linux.md) instructions.

## Changes

- **Xbox and PS2 save import:** preview profiles before importing, keep existing
  profiles by default, and explicitly back up before replacement. Optional shared
  unlock import preserves native preferences and leaderboards. Supports extracted
  Xbox saves/ZIPs and PS2 MAX, CBS, SPS/XPS, PSU, PSV, ZIP and folder exports;
  whole memory cards and save states need exporting first. See the
  [save import guide](../importing-saves.md) ([PR #295](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/295)).
- **Subtitle size:** normal, large (1.30×) and extra large (1.65×), applied live
  in Interface → Language and subtitles
  ([PR #309](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/309)).
- **Mod update notice:** Home shows “Mods (Updates Available)” when the signed
  catalogue offers an update. Its silent background check follows the existing
  update switch and cannot block Play
  ([PR #311](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/311)).
- **RecompLauncher manifest:** repository data for Modern/Original, Skip intro
  and an optional copy check. Applying it to the external catalogue remains a
  separate maintainer step; no Easy Setup or package integration is added
  ([PR #314](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/314)).

## Downloads and updating

Windows x64: `DefJamRecompiled-1.2.3-windows-x64.exe`; Apple Silicon macOS:
`DefJamRecompiled-1.2.3-macos-arm64.zip`; Linux / Steam Deck:
`DefJamRecompiled-1.2.3-linux-x86_64.AppImage`. Each has a SHA-256 sidecar and
source/toolkit provenance. Keep your existing data folder when updating.
