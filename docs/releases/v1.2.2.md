# v1.2.2 — Team Match fixes and diagnostics

Custom fighters now keep their correct identity through Team Match selection
and results. This patch also improves voice-subtitle state handling, adds a
Windows Game logs shortcut and improves fighter-fork integration and test evidence.

You need your own supported USA Xbox dump. The game-free app verifies it and
compiles locally; no game executable, fighter pack or game data is included.
For source builds, recursively clone tag `v1.2.2` and follow the
[Windows build instructions](../build-and-play.md) or the
[macOS/Linux instructions](../build-macos-linux.md).

## Changes

- **Custom fighters in Team Match:** map Choose Teams selections to participant
  banks and resolve Match Summary entries by native fighter identity. This
  addresses the wrong fighter appearing and the result-screen identity stop
  reported in [#293](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/293)
  ([PR #294](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/294)).
- **Voice subtitles:** synchronize active subtitle state between game and render
  threads, clear active text at match reset and report speech-handle pool overflow
  ([PR #259](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/259)). Speech
  subtitles and Story rematch already shipped in 1.2.0; this is their follow-up.
- **Windows Game logs shortcut:** launcher Help offers Open and Copy path for
  the installed game's logs separately from the app's Play logs
  ([PR #297](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/297),
  [#296](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/296)).
- **Fork integration:** build-time fighter bank/logical ranges and a shared
  resolver for five compiler base inputs support FFNY Online integration.
  Default ranges and original-dump behavior remain the same. Alternate ranges
  require the fork's own native qualification; patched inputs and networking
  are not supplied by this release
  ([PR #275](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/275)).
- **Test evidence:** Story routes validate a prepared single-career fixture;
  reports retain fighter/venue assertions and the actual build compiler receipt.
  An opt-in result-to-main-menu route checks the ordered transition
  ([PR #298](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/298)).

## Downloads and updating

- Windows x64: `DefJamRecompiled-1.2.2-windows-x64.exe`.
- macOS Apple Silicon: `DefJamRecompiled-1.2.2-macos-arm64.zip`.
- Linux / Steam Deck: `DefJamRecompiled-1.2.2-linux-x86_64.AppImage`.

Each game-free app has its SHA-256 and source/toolkit provenance. Keep the
existing data folder when updating. Fighter caches whose manifest/range identity
changes are rebuilt before play; a failed mismatch rebuild refuses the
incompatible pack. Windows/macOS unsigned-app guidance is in the
[install guide](../install-guide.md).

## Qualification limits

New native qualification for this candidate is Windows. macOS/Linux package
builds and hardware-free fixtures pass hosted CI. Prior native qualifications
remain applicable only to unchanged stock paths; their original failures and
scope are retained in the [1.2.0 qualifications](v1.2.0.md#testing-and-limits)
and [1.2.1 notes](v1.2.1.md#validation-and-limits). No fresh macOS/Deck gameplay
run or owner hands-on play-test is claimed for 1.2.2.

Multiple custom fighters on both teams, two human players, alternate ranges in
a real match, arbitrary patched base inputs and every voice-pack configuration
have not been broadly qualified. PR #275's earlier contended/interrupted runs
remain failed or incomplete evidence; this stock candidate pass does not
retroactively change those results. Existing HD CAF limits (#283), memory
investigation (#166), Deck replay issue (#98), startup report (#285) and fighter
follow-ups (#247) remain open. The v1.3.0 milestone is outside this release.
