# v1.2.2 — Team Match fixes and diagnostics

Release candidate: qualification is pending. v1.2.1 remains the published release.
The full native regression will start only when the owner instructs it; publication
depends on successful qualification. No v1.2.2 release or tag has been published.

You need your own supported USA Xbox dump. The game-free app verifies it and
compiles locally; no game executable, fighter pack or game data is included.
For source builds, recursively clone the candidate branch and follow
[Windows build instructions](../build-and-play.md) or the
[macOS/Linux instructions](../build-macos-linux.md).

## Changes

- **Custom fighters in Team Match:** map Choose Teams selections to their
  participant banks and resolve Match Summary entries by native fighter identity.
  This addresses the wrong fighter appearing and the result-screen identity stop
  reported in [#293](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/293)
  ([PR #294](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/294)).
- **Voice subtitles:** synchronize active subtitle state between game and render
  threads, clear active text at match reset and report speech-handle pool overflow
  ([PR #259](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/259)).
  Speech subtitles and Story rematch support already shipped in 1.2.0; this
  release contains the remaining follow-up changes from that branch.
- **Windows Game logs shortcut:** launcher Help offers Open and Copy path for
  the installed game's logs when they differ from the app's Play logs
  ([PR #297](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/297),
  [#296](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/296)).
- **Fork integration:** build-time fighter bank/logical ranges and a shared
  resolver for five fighter-compiler base inputs support FFNY Online integration.
  Default ranges and original-dump behavior remain the same. Alternate ranges
  require the fork's own native qualification; patched base files and networking
  are not supplied by this release
  ([PR #275](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/275)).
- **Test evidence:** Story routes validate an explicitly prepared single-career
  fixture; reports retain fighter/venue assertions and the actual build compiler
  receipt. An opt-in result-to-main-menu route adds an ordered transition check
  ([PR #298](https://github.com/vyanhursky/DefJamFFNY-recomp/pull/298)).

## Downloads and updating

After publication, the three game-free packages will be:

- Windows x64: `DefJamRecompiled-1.2.2-windows-x64.exe`.
- macOS Apple Silicon: `DefJamRecompiled-1.2.2-macos-arm64.zip`.
- Linux / Steam Deck: `DefJamRecompiled-1.2.2-linux-x86_64.AppImage`.

Each app has its SHA-256 and source/toolkit provenance. Keep the existing data
folder when updating. Fighter caches whose manifest/range identity changes are
rebuilt before play; a failed mismatch rebuild refuses the incompatible pack.
