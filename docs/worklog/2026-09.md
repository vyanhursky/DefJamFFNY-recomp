- 2026-09-17 20:30 — **Second toolkit bug class found: truncated jump tables.** The two unresolved ICALLs are not functions at all. `sub_002016B0` is the CRT `memmove`/`memcpy`; MSVC dispatches its alignment and tail cases through jump tables embedded in the body (`jmp dword ptr [edx*4 + 0x2017FC]`). Function detection ends the body at 0x00201952, but the arms live at 0x0020194C–0x002019D4, past that end, so `_analyze_switch_table` (which requires `func_start <= target < func_end`) rejected them and the lifter emitted an indirect call instead of a `goto`. `rep movsd` still copied the aligned bulk, so only head/tail bytes were lost — which is exactly how a half-written pointer becomes the null indirect call that spun 100k+ times. A repo-wide scan says **17 of 423 indexed jumps** have arms past their function's end (`sub_001D5270` and a cluster in the CRT copy family; 8 more sites sit in undetected functions). **Iteration 12**: native `memmove` override for 0x002016B0 in `src/recomp_manual.c` — both the correctness fix and a large speed-up. - 2026-09-19 11:00 — **Blocker identified precisely.** Dense thread sampling (40 samples at 150 ms) caught a thread pinned in guest `sub_00267B3D`, inside DirectSound. The polled addresses were confirmed by reading the runtime table at guest `0x0027C4C8` out of the live process: they are `0xFEC0010B`, `0xFEC0011B`, `0xFEC0014B`, `0xFEC0017B` and `0xFEC0210B`.

- 2026-09-19 16:15 — **Why it draws nothing, precisely.** The translator was written against Burnout 3's menu profile and only understands `NV097_INLINE_ARRAY`, where vertex data arrives inline in the command stream. This title submits **indexed draws from vertex arrays in memory**: our executor counts 12,202 draws and 48,808 indices, four per draw, all through `NV097_ARRAY_ELEMENT16`, with the attribute offsets and formats set up by `SET_VERTEX_DATA_ARRAY_OFFSET`/`_FORMAT`. That is a real feature addition rather than more plumbing, but it is bounded: the executor already resolves the array addresses and formats, so the data is in hand.
